Keeps the page tree and this module pointing at the same page, the same handshake the page view does: the tree writes the selected uid into ModuleStateStorage, and a module that does not update it sends the reader back to a different page the next time they switch.
Prose beside the table, not a tooltip on it. The reason to build a module at all is room to say what a figure means, and hiding that behind a hover would be the same mistake in a new place.

"Decay" is a word this view invents, so it is the one the reader has to be told the meaning of. Spelled out beside the table rather than hidden behind a hover, and long on purpose: the column makes a claim about a page, and a claim nobody can check is worse than none.

aria-sort is "none" on every column but the one actually sorted, and the header is a real link rather than a clickable cell, so the keyboard reaches it and the browser can say where it goes. The decay column sits next to the trend because the two are read together: the trend is the fall, this is the neglect, and the verdict is only the two at once. Sortable exactly like a metric header, with the same aria-sort and the same real link, because it is a column of this table and not a mode the table is put into.
