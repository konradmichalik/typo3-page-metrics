The foot of a widget's site block: one link into the module, for the site whose numbers are above it. Written once here because six widgets carry it and a link that says something different in each of them would read as six different destinations. The map is keyed by site identifier and holds no entry for a site this reader may not open the module on, so an absent key is the whole of the access decision (see ModuleLinkBuilder). The site's name goes into the accessible name but is not drawn: a dashboard can show several of these at once, and "Open full view" three times over tells a screen-reader user nothing about which is which. No tooltip here, unlike the same link in the page module's tile row: the house tooltip is bound by sparkline.js, and most of these widgets load no JavaScript at all.
