A key to the marker colours on the chart above, listing only the kinds actually drawn. Seven entries under a chart carrying two would be a key to colours that are not there. Each entry pairs the colour with the category's own icon and its name, so the colour is never the only thing saying which kind an event was. Entries arrive already prepared as arrays rather than as the enum itself: Fluid resolves properties and getters, and a backed enum's icon() and label() are neither. Arguments: categories the kinds drawn, each an array of value, icon and label
