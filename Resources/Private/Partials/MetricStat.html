One stat chip (Metrics breakdown widget) - the same icon, value and hint the tile's own popover shows for last day / previous day / peak / average / via redirects, reused here for a widget with no hover of its own to open that popover from. The five icons are sparkline.js's STAT_ICON_PATHS, copied rather than shared: none of them are registered core:icon identifiers, and this extension already makes the same tradeoff for PageHeader/Metrics.html's inline checkmark rather than invent a bridge from a JS constant to PHP for five paths that never change. Arguments: key which stat this is - lastDay, previousDay, peak, average or viaRedirects - selects the icon label the chip's short label, e.g. "Peak" value the chip's already formatted value, e.g. "160" hint the explanation shown on hover, e.g. "The highest value a single day reached"
{value} The icon and the pill's shape carry nothing on their own for assistive technology or a forced-colours mode - the same reasoning the trend badge's own visually-hidden sentence follows. {label}. {hint}
